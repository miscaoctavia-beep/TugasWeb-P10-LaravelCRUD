# Tugas Web Pertemuan 9 — Laravel Setup

## Deskripsi
Project ini dibuat untuk memenuhi Tugas Rutin 9 Pemrograman Web menggunakan Laravel.

## Teknologi
- PHP 8.2
- Laravel 12
- Composer
- MySQL
- XAMPP
- Blade Template

## Fitur
- Halaman utama `/`
- Halaman layout `/layout`
- Halaman contact `/contact`
- Data mahasiswa menggunakan array
- Controller `PageController`
- Model `Product`

## Cara Menjalankan

1. Pastikan Apache dan MySQL aktif melalui XAMPP.
2. Buka terminal pada folder project.
3. Jalankan:

```bash
php artisan serve
